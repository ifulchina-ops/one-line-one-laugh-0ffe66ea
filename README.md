One sharp, funny one-liner: a smoke alarm that only ever sounds while its owner cooks stops being a safety device and becomes a food critic. The program writes the line to `entry.txt` — one line, 103 characters, no setup needed.

> My smoke alarm goes off every time I cook. At this point it's less a fire alarm and more a food critic.

## Why it lands

The setup is an everyday annoyance — an alarm that screams at dinner, never at a real fire. The punchline reframes the alarm as a critic: it is not warning anyone, it is reviewing the cooking. One image, one turn, nothing to explain.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is unset. It needs Node 22.18 or later, no dependencies, no network — the same line on every run.
